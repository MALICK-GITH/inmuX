Très bonne question !
Tu peux lancer un script .sh dans Termux sans utiliser nano (donc sans avoir à l’éditer) en suivant ces étapes simples :


---

1. Place ton script dans un dossier accessible

Par exemple, si tu l’as téléchargé depuis un lien ou copié depuis Download :

mv /sdcard/Download/ton_script.sh ~/


---

2. Donne-lui les droits d’exécution

chmod +x ton_script.sh


---

3. Exécute-le

./ton_script.sh

Ou si tu préfères utiliser bash directement :

bash ton_script.sh


---

Exemple avec ton outil :

chmod +x solitaire_hack_inmux.sh
bash solitaire_hack_inmux.sh


---
